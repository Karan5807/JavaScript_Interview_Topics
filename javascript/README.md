# 🟨 JavaScript Interview Topics

This section covers key JavaScript concepts commonly asked in interviews, from basics to advanced patterns.

## 🔹 Core Concepts

- Data types and coercion
- Scope, closures, and hoisting
- `this` keyword and context
- Prototypes and inheritance
- Event loop and concurrency

## 🔹 ES6+ Features

- Arrow functions, `let`/`const`
- Destructuring and spread/rest
- Promises and async/await
- Modules and imports

## 🔹 Advanced Topics

- Debouncing and throttling
- Currying and composition
- Memory leaks and garbage collection
- Functional vs OOP paradigms

## 🔹 Sample Questions

- Explain event delegation in JavaScript.
- What is the difference between `==` and `===`?
