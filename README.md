# 💡 Interview Topics: JavaScript, TypeScript, React.js, Node.js

This repository is a curated collection of essential interview topics and questions for web developers.

Whether you're preparing for a junior role or aiming for a full-stack development position, this guide covers core concepts, advanced patterns, coding questions, and practical examples across:

- 🟨 JavaScript
- 🔷 TypeScript
- ⚛️ React.js
- 🌐 Node.js

Each folder contains topic-wise breakdowns, important interview questions, sample code, and concise explanations to help you revise and practice effectively.

## 📂 Folder Overview

- [`javascript/`](./javascript/README.md) – Covers JavaScript fundamentals, ES6+, closures, promises, async patterns, DOM manipulation, and tricky interview questions.
- [`typescript/`](./typescript/README.md) – Covers TypeScript fundamentals, data types, interfaces, type aliases, generics, utility types, advanced patterns, and important interview questions.
- [`react/`](./react/README.md) – Focuses on React hooks, lifecycle, state management, performance optimization, and component architecture.
- [`node/`](./node/README.md) – Includes backend concepts, Node.js internals, event loop, Express.js, middleware, RESTful APIs, and database integration.

## 🚀 How to Use

1. Clone the repository:

   ```bash
   git clone https://github.com/your-username/interview-topics.git
   cd interview-topics
   ```

2. Explore each folder and start preparing topic by topic.

3. Practice the coding questions and try implementing concepts yourself before checking solutions.

4. Revise important interview questions and strengthen your understanding with practical examples.
